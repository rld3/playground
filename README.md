# Earnings Desk

A PayPal-focused institutional equity sales preparation prototype. Choose a growth, value, or long/short client lens, import public earnings text, inspect exact evidence passages, and export a source-linked conversation draft.

## Run

Requires Node.js 20 or newer. From `/workspace/playground`:

```sh
npm ci --cache /tmp/npm-cache
npm start
```

The server listens on port 3000; override with `PORT`. There are no production package dependencies, API keys, or build steps. Nothing is deployed automatically.

## Test

```sh
npm test
```

Browser tests use `/usr/bin/chromium` via Playwright. On another machine, install Chromium or adjust `playwright.config.js` to use your installed browser. Tests cover client lenses, evidence import, exact excerpts, source-linked export, unsafe URL rejection, and mobile layout. Synthetic values exist only in tests and are explicitly labeled.

## Sourced PayPal example

The default brief uses **Q2 2026**, released July 28, 2026, the latest earnings identified in SEC submissions when checked October 11, 2026. This is a dated snapshot, not an automatically refreshed feed.

- [Earnings release, 8-K Exhibit 99.1](https://www.sec.gov/Archives/edgar/data/1633917/000163391726000080/pypl2q-26earningsrelease.htm)
- [Matching Form 10-Q](https://www.sec.gov/Archives/edgar/data/1633917/000163391726000082/pypl-20260630.htm)
- [SEC submissions used for recency check](https://data.sec.gov/submissions/CIK0001633917.json)

`public/paypal-data.js` contains the curated brief, company-reported comparative figures, editorial client lenses, and exact supporting excerpts. Whitespace-normalized source text is retained in `public/materials/`, alongside a manifest with original URLs, retrieval date, and SHA-256 hashes. Tables are flattened in extracted text: consult the original SEC document for table layout. Core GAAP revenue, operating income, and EPS were reconciled between the release and 10-Q. No transcript or consensus estimates are used. Guidance is explicitly dated and separated from outcomes.

## Demo flow

1. Review the populated Q2 2026 example and choose a growth, value, or long/short client lens.
2. Inspect citations on performance metrics, factual context, outlook, and risks. The evidence panel links to original SEC documents and downloadable source text.
3. Export a plain-text brief with source references, dated management guidance, and the selected conversation questions.
4. **New brief** starts an independent PayPal draft from pasted or uploaded UTF-8 `.txt` content. Submit to replace the example; cancel leaves the existing brief intact. User imports are not marked verified and do not inherit the curated metrics.
5. **Add source** adds supporting text for the existing reporting period. Click PayPal in the coverage sidebar to restore the curated example.

Imported documents remain in page memory and are cleared on refresh. No text is sent to a model or backend. Refresh restores the public sourced example.

## Remaining prototype limitations

The preloaded brief is curated, not generated by an AI model. New-document extraction uses deterministic passage matching. User-provided URLs are linked but not fetched or verified. General-purpose numerical extraction, cross-document reconciliation for new uploads, PDF parsing, and AI synthesis remain unimplemented. Reported facts, management guidance, and editorial interpretations are labeled separately; no consensus beat/miss is inferred.

## Publishing

The public site is hosted at https://rld3.github.io/playground/ using the `gh-pages` branch. The branch contains the contents of `public/` at its root; asset links are relative so the repository subpath works. The development code lives on `main`. Preserve deployment history when publishing a new tree; do not force-push. Source changes alone do not update Pages until the public tree is pushed to `gh-pages` and GitHub completes its build.
